## 📖 معرفی

**XpnManage** فقط یک فایل `index.php` است که دو نقش دارد:

1. **صفحهٔ کاربری (برای مرورگر):** وقتی کاربر لینک اشتراکش را در مرورگر باز می‌کند، به‌جای متن خام کانفیگ‌ها یک داشبورد واکنش‌گرا (فارسی/انگلیسی) می‌بیند؛ شامل وضعیت سرویس، حجم و زمان باقی‌مانده، نمودار مصرف، QR Code لینک اشتراک، راهنمای نصب برنامه‌ها و راه ارتباط با پشتیبانی.
2. **پروکسی به پنل (برای کلاینت‌های VPN):** وقتی همان لینک را یک برنامهٔ VPN باز می‌کند، درخواست با همان مسیر به پنل اصلی فرستاده می‌شود و پاسخ آن (محتوای اشتراک و هدرهای لازم) به کلاینت برمی‌گردد.

نتیجه: کاربران فقط با دامنهٔ شما در تماس‌اند و آدرس واقعی پنل در لینک اشتراک و صفحه دیده نمی‌شود.

## ✨ امکانات

- 📊 **داشبورد کاربر** — وضعیت سرویس (فعال، غیرفعال، حجم تمام‌شده، منقضی‌شده، در انتظار اتصال)، حجم باقی‌مانده، روزهای باقی‌مانده و تاریخ پایان؛ با رنگ‌بندی هشدار (سبز، زرد، قرمز) بر اساس باقی‌ماندهٔ حجم و زمان
- 🔮 **پیش‌بینی مصرف** — از روی میانگین مصرف ۷ روز اخیر می‌گوید حجم کاربر کی تمام می‌شود و این زمان قبل یا بعد از پایان سرویس است؛ با نوار «مصرف‌شده / پیش‌بینی تا پایان سرویس»
- 📈 **نمودار مصرف** — بازه‌های 24 ساعت، 7 روز، 30 روز، 12 ماه و «همه»، همراه با مجموع، میانگین و بیشینهٔ مصرف (نمودار میله‌ای ساده، بدون کتابخانهٔ نمودار)
- 🔗 **لینک اشتراک** — کپی با یک کلیک، QR Code و نمای بزرگ‌شدهٔ آن برای اسکن راحت‌تر
- 📱 **راهنمای اتصال** — فهرست برنامه‌ها به تفکیک سیستم‌عامل (iOS/macOS، Android، Windows، Linux) با دکمهٔ دانلود، افزودن خودکار کانفیگ (Deep Link) و آموزش ویدیویی
- 🛟 **پشتیبانی** — صفحهٔ پشتیبانی تلگرام با نمایش «باز/بسته» بودن بر اساس ساعت کاری (به وقت ایران)، شمارندهٔ زمان باقی‌مانده تا باز/بسته شدن و دکمهٔ پیام در تلگرام
- ⚠️ **اعلان پایان سرویس** — پنجرهٔ هشدار هنگام اتمام حجم یا انقضای سرویس، همراه با دکمهٔ خرید/تمدید
- 🎨 **ظاهر و تم** — حالت تاریک/روشن و 6 تم رنگی: سیاه‌وسفید (پیش‌فرض)، رویای کیهانی، سبز، زرد، بنفش و کریسمس (آسمان شفق قطبی، افق جنگل کاج، بارش برف روی Canvas، ریسهٔ نور طلایی، گوی‌های آویز و شمارش معکوس تا کریسمس)
- 📲 **نصب به‌شکل اپ (PWA)** — کاربر صفحه را به صفحهٔ اصلی گوشی اضافه می‌کند؛ بدون اینترنت، آخرین اطلاعات ذخیره‌شده با پیام «اتصال برقرار نشد» نمایش داده می‌شود
- 🪶 **حالت سبک** — کلیدی در تنظیمات که انیمیشن‌ها، برف و افکت‌های شیشه‌ای را برای گوشی‌های ضعیف خاموش می‌کند
- 🌐 **دو زبانه** — فارسی (راست‌به‌چپ) و انگلیسی؛ انتخاب کاربر در مرورگر ذخیره می‌شود
- 🛡️ **امنیت** — فقط مسیرهای مجاز (پیش‌فرض `/sub/`)، فقط `GET`/`HEAD`، رد مسیرهای مخرب، محدودیت تعداد درخواست برای هر IP و هدرهای امنیتی (`no-referrer` برای جلوگیری از نشت توکن، `noindex`، منع نمایش در iframe)
- ⚡ **سبک و سریع** — فشرده‌سازی gzip، کش HTML با ETag (پاسخ 304)، حالت سبک برای دستگاه‌های ضعیف یا Data Saver و رعایت `prefers-reduced-motion`
- ♿ **دسترس‌پذیری** — برچسب‌های ARIA، ناوبری با کیبورد در منوی زبان و قفل فوکوس در پنجرهٔ هشدار

## ⚙️ نحوهٔ کار

| درخواست | رفتار |
|---|---|
| بدون `User-Agent` | ریدایرکت به `/` |
| مرورگر (هدر `Accept` شامل `text/html`) | نمایش صفحهٔ کاربری؛ داده‌ها را خود صفحه با JavaScript از `/info` و `/usage` روی لینک اشتراک می‌گیرد |
| هر درخواست دیگر (کلاینت‌های VPN، `/info`، `/usage` و …) | پروکسی با cURL (فقط `GET`) به `base_url` + همان مسیر درخواست |

از پاسخ پنل فقط این هدرها به کلاینت برگردانده می‌شود: `Content-Type`، `Content-Disposition`، `Subscription-Userinfo` و `Profile-Update-Interval`. کد وضعیت HTTP پنل (مثلاً 404 برای توکن اشتباه) هم منتقل می‌شود تا صفحه بتواند خطا را تشخیص دهد.

### ساختار فایل

`index.php` از سه بخش پشت‌سرهم تشکیل شده است:

1. **PHP:** تنظیمات (`$CONFIG` و `config.php`)، بررسی‌های امنیتی و محدودیت درخواست، فایل‌های اپ (manifest، service worker و آیکن با `?xpn=`)، تشخیص درخواست مرورگر، ETag و gzip
2. **HTML / CSS / JS:** خود صفحه (همه‌چیز داخل همین فایل است)
3. **PHP:** پروکسی cURL به پنل (`base_url`)

## 🧩 پیش‌نیازها

- **PHP 8.0 یا بالاتر** (به‌دلیل استفاده از `str_contains`) با افزونهٔ **cURL**؛ افزونهٔ `zlib` اختیاری است و برای gzip استفاده می‌شود
- وب‌سرور Apache یا Nginx (یا هر هاست PHP که اجازهٔ هدایت همهٔ مسیرها به `index.php` را بدهد؛ هاست اشتراکی/cPanel هم کافی است)
- پنلی که روی لینک اشتراک، مسیرهای `/info` و `/usage` را ارائه می‌دهد (مثل Marzban)؛ قالب پاسخ‌ها در بخش «پاسخ‌های موردانتظار از پنل» آمده است

## 🚀 نصب و راه‌اندازی

### 1. آپلود فایل

فایل `index.php` را در ریشهٔ دامنه یا ساب‌دامینی که می‌خواهید لینک اشتراک کاربران از آن ارائه شود قرار دهید.

### 2. تنظیمات

همهٔ تنظیمات در آرایهٔ `$CONFIG` در **ابتدای** `index.php` است. پیشنهاد بهتر: یک فایل `config.php` کنار `index.php` بسازید و فقط کلیدهایی را که می‌خواهید عوض کنید در آن بنویسید. مقادیر `config.php` بر پیش‌فرض‌ها برتری دارند؛ پس وقتی نسخهٔ جدید `index.php` را جایگزین می‌کنید، تنظیمات شما از دست نمی‌رود.

<div dir="ltr">

```php
<?php
return [
    'base_url'     => 'https://panel.example.com:443', // فقط پروتکل، دامنه و پورت؛ بدون / پایانی و بدون مسیر
    'brand'        => 'MyVPN',
    'support_id'   => 'MySupport',                     // آیدی تلگرام، بدون @
    'support_from' => 9,
    'support_to'   => 24,
];
```

</div>

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `base_url` | — | آدرس پنل |
| `brand` | `XpnTeam` | نام برند در سربرگ، عنوان تب و نام اپ نصب‌شده |
| `support_id` | `XpnAdmin` | آیدی تلگرام پشتیبانی (بدون @) |
| `support_from` / `support_to` | `9` / `24` | ساعت کاری پشتیبانی (۲۴ ساعته)؛ متن ساعت‌ها خودکار ساخته می‌شود |
| `support_tz` | `Asia/Tehran` | منطقهٔ زمانی ساعت کاری |
| `default_theme` | `mono` | تم بازدید اول: `mono`، `violet`، `green`، `yellow`، `purple` یا `xmas` |
| `default_mode` | `dark` | حالت بازدید اول: `dark` یا `light` |
| `allowed_paths` | `['/sub/']` | فقط مسیرهایی که با این‌ها شروع شوند پاسخ می‌گیرند؛ `[]` یعنی همهٔ مسیرها |
| `rate_limit` | `120` | حداکثر درخواست در دقیقه از هر IP؛ `0` یعنی بدون محدودیت |
| `behind_cloudflare` | `false` | فقط اگر سایت واقعاً پشت Cloudflare است `true` کنید تا IP واقعی کاربر از `CF-Connecting-IP` خوانده شود |

💡 **نکته:** مسیر لینک اشتراک روی دامنهٔ شما باید دقیقاً همان مسیر روی پنل باشد. مثلاً اگر لینک روی پنل `https://panel.example.com:443/sub/TOKEN` است، لینک کاربر `https://sub.example.com/sub/TOKEN` خواهد بود.

💡 اگر مسیر لینک اشتراک پنل شما `/sub/` نیست (مثلاً `/s/`)، `allowed_paths` را مطابق آن تغییر دهید؛ وگرنه همهٔ درخواست‌ها خطای 404 می‌گیرند.

### 3. هدایت همهٔ مسیرها به `index.php`

لینک اشتراک هر کاربر یک مسیر جداست (مثلاً `/sub/TOKEN`)؛ پس وب‌سرور باید همهٔ مسیرها را به `index.php` بدهد.

**Apache / cPanel** — فایل `.htaccess` کنار `index.php`:

<div dir="ltr">

```apache
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteRule ^ index.php [L]
```

</div>

**Nginx:**

<div dir="ltr">

```nginx
server {
    listen 443 ssl;
    server_name sub.example.com;
    root /var/www/xpnmanage;

    # ssl_certificate و ssl_certificate_key را اینجا تنظیم کنید

    location / {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root/index.php;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;  # مطابق نسخهٔ PHP سرور خودتان
    }
}
```

</div>

⚠️ لینک اشتراک شامل توکن کاربر است؛ حتماً از HTTPS استفاده کنید.

### 4. تست

- در مرورگر `https://sub.example.com/sub/TOKEN` را باز کنید؛ باید داشبورد نمایش داده شود.
- نصب به‌شکل اپ (PWA) فقط روی HTTPS کار می‌کند.

## 🔌 پاسخ‌های موردانتظار از پنل

در ادامه، `{SUB_URL}` همان لینک اشتراک کاربر است (مثلاً `https://sub.example.com/sub/TOKEN`).

### `GET {SUB_URL}/info`

<div dir="ltr">

```json
{
  "username": "user1",
  "status": "active",
  "data_limit": 53687091200,
  "used_traffic": 1073741824,
  "lifetime_used_traffic": 5368709120,
  "expire": 1767225600
}
```

</div>

| فیلد | توضیح |
|---|---|
| `username` | نام کاربر؛ در خوش‌آمدگویی صفحه و عنوان تب نمایش داده می‌شود |
| `status` | یکی از `active`، `disabled`، `limited`، `expired` یا `on_hold` (پیش‌فرض: `active`) |
| `data_limit` | سقف حجم به بایت؛ `0` یا خالی یعنی نامحدود |
| `used_traffic` | حجم مصرف‌شده به بایت |
| `lifetime_used_traffic` | مصرف کل در طول عمر سرویس؛ اگر نباشد، `used_traffic` نمایش داده می‌شود |
| `expire` | زمان پایان سرویس؛ Unix timestamp (ثانیه یا میلی‌ثانیه) یا رشتهٔ تاریخ؛ `0` یا خالی یعنی نامحدود |

### `GET {SUB_URL}/usage`

پارامترها:

- `period`: برابر `hour` (بازهٔ 24 ساعت)، `day` (7 و 30 روز) یا `month` (12 ماه و «همه»)
- `start` و `end`: زمان شروع و پایان با قالب ISO 8601 (UTC)

<div dir="ltr">

```json
{
  "stats": {
    "-1": [
      { "period_start": "2026-01-01T00:00:00", "total_traffic": 1048576 }
    ]
  }
}
```

</div>

صفحه آرایهٔ کلید `-1` (یا اولین کلید موجود) را در نمودار رسم می‌کند.

## 🛠️ شخصی‌سازی

| چه چیزی | کجا |
|---|---|
| آدرس پنل، برند، پشتیبانی، تم پیش‌فرض، امنیت | `config.php` یا آرایهٔ `$CONFIG` در ابتدای فایل |
| متن‌ها | دیکشنری `T` (کلیدهای `fa` و `en`)؛ `{b}` در متن‌ها با نام برند جایگزین می‌شود |
| آیکن اپ نصب‌شده | ثابت‌های base64 در بخش `xpn=icon` (PNG مربعی 192 و 512 پیکسل) |
| افزودن زبان جدید | افزودن یک کلید به `T` و `LN` و یک گزینه به منوی زبان (`#lgm`) |
| رنگ‌ها و تم‌ها | متغیرهای CSS در `:root` و بلوک‌های `[data-accent=…]`؛ برای تم جدید یک دکمه در بخش تنظیمات و یک مقدار در آرایهٔ `AC` اضافه کنید |
| منبع فهرست برنامه‌ها | آدرس `os.json` در اسکریپت صفحه (جستجو کنید: `os.json`) |

### قالب فایل `os.json`

فهرست برنامه‌ها از یک فایل JSON خوانده و 12 ساعت در `localStorage` مرورگر کش می‌شود. اگر می‌خواهید فهرست خودتان را داشته باشید، همین قالب را در یک آدرس عمومی بگذارید و آدرس را در کد عوض کنید:

<div dir="ltr">

```json
{
  "operatingSystems": [
    {
      "name": "اندروید",
      "engName": "Android",
      "apps": [
        {
          "name": "MyApp",
          "faDescription": "توضیح فارسی برنامه",
          "description": "English description",
          "downloadLink": "https://example.com/download",
          "configLink": "myapp://import/{url}",
          "videoLink": "https://example.com/tutorial",
          "isAd": false
        }
      ]
    }
  ]
}
```

</div>

- `{url}` در `configLink` با لینک اشتراک کاربر جایگزین می‌شود.
- اگر `isAd` برابر `true` باشد، دکمهٔ دانلود نمایش داده نمی‌شود.
- آیکن سیستم‌عامل از روی `engName` انتخاب می‌شود (Apple/iOS/Mac، Android، Windows، Linux؛ در غیر این صورت آیکن عمومی).
- لینک‌هایی که با `javascript:`، `data:` یا `vbscript:` شروع شوند نادیده گرفته می‌شوند.

## 🌍 وابستگی‌های خارجی

مرورگر کاربر این منابع را بارگیری می‌کند:

- **Google Fonts:** فونت‌های Vazirmatn و Inter و Material Icons
- **cdnjs:** کتابخانهٔ QRCode.js
- **raw.githubusercontent.com:** فهرست برنامه‌ها (`os.json`)

اگر هرکدام در دسترس نباشد، صفحه همچنان کار می‌کند و فقط همان بخش (فونت، آیکون، QR یا فهرست برنامه‌ها) ممکن است نمایش داده نشود؛ مثلاً به‌جای QR، متن لینک اشتراک نشان داده می‌شود. برای حذف این وابستگی‌ها می‌توانید فایل‌ها را روی سرور خودتان میزبانی کنید و آدرس‌ها را در کد عوض کنید.

## 🔒 نکات امنیتی و عملیاتی

- فقط درخواست‌های `GET` به پنل ارسال می‌شود و هیچ کوکی یا هدر احراز هویتی از کاربر به پنل عبور داده نمی‌شود.
- فقط مسیرهای `allowed_paths` به پنل پروکسی می‌شوند و بقیه خطای 404 می‌گیرند. مسیرهای مشکوک (`..`، `//`، بک‌اسلش، کاراکترهای کنترلی) خطای 400 و متدهای غیر از `GET`/`HEAD` خطای 405 می‌گیرند.
- محدودیت تعداد درخواست (`rate_limit`) در پوشهٔ موقت سیستم ذخیره می‌شود؛ اگر آن پوشه قابل نوشتن نباشد، محدودیت بی‌صدا غیرفعال می‌شود تا کاربری قفل نشود. پشت Cloudflare یا پروکسی دیگر، بدون `behind_cloudflare` همهٔ کاربران یک IP دیده می‌شوند؛ در آن حالت یا آن را فعال کنید یا `rate_limit` را `0` بگذارید.
- هدر `Referrer-Policy: no-referrer` نمی‌گذارد توکن داخل آدرس به سایت‌های دیگر (فونت‌ها، تلگرام و…) فرستاده شود.
- پنل آی‌پی سرور شما را می‌بیند، نه آی‌پی واقعی کاربر (هدر `X-Forwarded-For` ارسال نمی‌شود). اگر پنل شما بر اساس آی‌پی لاگ یا محدودیت دارد، این را در نظر بگیرید.
- زمان‌بندی درخواست به پنل: حداکثر 5 ثانیه برای اتصال و 15 ثانیه برای کل درخواست.
- گواهی SSL پنل بررسی می‌شود؛ گواهی خودامضا باعث خطای 502 می‌شود.

## 🩺 عیب‌یابی

| علامت | علت احتمالی و راه‌حل |
|---|---|
| `Please upgrade your PHP version to 8.0 or above` | نسخهٔ PHP پایین‌تر از 8.0 است؛ آن را ارتقا دهید |
| خطای 502 با متن `Upstream error` | اتصال به پنل برقرار نشد؛ `base_url`، فایروال، فعال‌بودن افزونهٔ cURL و اعتبار گواهی SSL پنل را بررسی کنید |
| خطای 502 با متن `Error! No valid headers found.` | پنل هدرهای موردانتظار را برنگردانده؛ معمولاً مسیر یا `base_url` اشتباه است |
| پیام «این لینک اشتراک معتبر نیست…» در صفحه | پنل برای این توکن خطای 4xx داده (توکن اشتباه یا کاربر حذف‌شده) یا مسیر با `allowed_paths` نمی‌خواند |
| پیام «سرور فعلاً پاسخ نمی‌دهد…» در صفحه | درخواست‌های `/info` به `index.php` نمی‌رسند (قوانین بازنویسی وب‌سرور را بررسی کنید) یا پنل در دسترس نیست (خطای 5xx) |
| ریدایرکت به `/` | درخواست بدون `User-Agent` ارسال شده است |
| خطای 404 با متن `Not Found` | مسیر لینک با `allowed_paths` شروع نمی‌شود |
| خطای 429 با متن `Too Many Requests` | از یک IP بیش از `rate_limit` درخواست در دقیقه رسیده؛ پشت Cloudflare، `behind_cloudflare` را فعال کنید |
| دکمهٔ «نصب اپ» در تنظیمات دیده نمی‌شود | سایت HTTPS نیست، مرورگر از نصب پشتیبانی نمی‌کند، یا صفحه قبلاً نصب شده است (در iPhone راهنمای Safari نمایش داده می‌شود) |
| QR، فونت یا فهرست برنامه‌ها نمایش داده نمی‌شود | دسترسی به منابع خارجی (cdnjs، Google Fonts یا GitHub) برقرار نیست |
